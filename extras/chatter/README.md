# 台词库（10 级机器人说话用）

初版台词库，分成两份：

- `enemy.zh_cn.txt`：说给对手听，制造竞技压力和精神压力
- `ally.zh_cn.txt`：说给同队玩家听，报点、掩护、配合，给队友安全感

## 文件格式

```
# 井号开头的行是注释，空行忽略
[enemy.lock_on] cd=60 p=0.8  # 类别头：类别 ID、参数、说明
看到你了。                     ← 一行一句
@冷血 找到你了。                ← 行首 @人设：只有这种人设会说
@嘲讽 ! 正好拿你热热身。         ← 行首 !：狠话
```

**类别头参数：** 写在 `[类别ID]` 后面。

| 参数 | 含义 | 默认 |
|---|---|---|
| `cd=秒` | 同一个机器人两次说这一类台词的最短间隔 | 30 |
| `p=0~1` | 事件发生时开口的概率 | 1 |
| `via=chat\|title\|actionbar` | 显示位置：聊天栏、屏幕中间大字、物品栏上方小字 | chat |

**台词行开头的标记：** 顺序随意，用空格隔开。
- `@分析` `@嘲讽` `@冷血` `@队长` `@阴人`：只给这种人设用。不写人设的台词，所有人设通用。
- `!`：狠话。聊天强度设为"温和"时不说。

**槽位：** `{槽位}` 会被替换成实时数据。某个槽位当时拿不到，就跳过这一句，换一句。

**类别可以随便加：** 代码还没用到的类别会被忽略，等对应事件实现了自然就会说。

## 人设

| 标记 | 人设 | 说话风格 |
|---|---|---|
| `@分析` | 冷静分析 | 报数据、算概率，像在实时复盘 |
| `@嘲讽` | 话痨嘲讽 | 嘴碎、玩梗、挑衅 |
| `@冷血` | 沉默行刑 | 话少、短句，像在预告结局 |
| `@队长` | 热血队长 | 指挥、鼓舞、喊集火 |
| `@阴人` | 老六 | 心理战、假动作、"我早就知道" |

每个机器人生成时分配一种人设（可以写进装备预设）。它只会从"自己的人设 + 通用"这两部分台词里挑。

## 槽位

| 槽位 | 含义 |
|---|---|
| `{player}` | 说话对象：对敌台词里是目标，对友台词里是那位队友 |
| `{bot}` | 说话的机器人自己的名字 |
| `{enemy}` | 敌人的名字（对友台词用） |
| `{ally}` | 机器人队友的名字（对敌台词里的队内喊话用） |
| `{distance}` | 距离，整数格数 |
| `{direction}` | 方位：东、南、西、北、东北、东南、西南、西北 |
| `{totems}` | 说话对象剩余的图腾数（包括副手） |
| `{gapples}` | 说话对象剩余的金苹果数（包括附魔金苹果） |
| `{my_totems}` | 机器人自己剩余的图腾数 |
| `{weapon}` | 说话对象主手拿的物品名 |
| `{piece}` | 快碎的那件盔甲：头盔、胸甲、护腿、靴子 |
| `{hp}` | 说话对象剩余的生命，按颗心算，四舍五入 |
| `{hits}` | 本局机器人命中对方的次数 |
| `{smashes}` | 本局重锤命中的次数 |
| `{accuracy}` | 对方本局的命中率（百分比数字） |
| `{deaths}` | 对方这次进服以来被机器人杀死的次数 |
| `{kills}` / `{bot_kills}` | 队友的击杀数 / 机器人的击杀数 |
| `{streak}` | 机器人当前的连杀数 |
| `{time}` | 本局已经打了多少秒 |
| `{cooldown}` | 对方的盾或武器还剩几秒冷却 |
| `{habit}` | 读人系统识别出的习惯，比如"被破盾就往左跑" |
| `{prediction}` | 预测的对方下一步，比如"扔珍珠""开鞘翅""吃金苹果" |
| `{buffs}` | 刚扔出去的药水效果，比如"力量、迅捷" |

## 几类特殊台词

- **真假共用：** `enemy.dive_warn`（俯冲预告）和 `enemy.retreat`（撤退）由真动作和假动作共用，对手听到时分不出真假。说完之后真俯冲、真撤退还是假动作，由 AI 决定。
- **故意给对手听：** `enemy.team_callout` 是机器人队友之间的喊话，故意发给对手看，制造被围猎的感觉。
- **整局数据：** `enemy.summary` 和 `ally.summary` 在击杀或一场结束后补一句整局数据。

## 给实现的建议

**谁能听到：**
- `enemy.*` 默认只私聊给目标本人。`enemy.team_callout` 发给附近所有敌人。
- `ally.*` 只发给同队的真人玩家。
- `via=title` 和 `via=actionbar` 也只发给对应的人。

**聊天显示：** 显示成 `<名字> 台词`，名字用队伍颜色。

**限频：**
- 每个类别按 `cd` 冷却，按机器人分别计。
- 同一个机器人两句话之间至少隔 6 秒。
- 每个听众每 2 秒最多收到 1 句，不管这句来自哪个机器人。

**选句：** 每个类别用"洗牌袋"选句，所有台词都说过一遍才重新洗牌，避免短时间内重复。

**强度开关：** 比如 `/bot settings chatter off|mild|spicy`，默认只在 10 级打开。`mild` 档跳过带 `!` 的台词。

**文件位置：**
- 放在服务端的 `config/terminatorplus/chatter/`，用一条命令（比如 `/bot chatter reload`）重新加载。
- jar 里带一份默认文件，第一次启动时复制出去。

**事件来源：**
- 大部分事件现在就能拿到：锁定目标、爆图腾、吃东西、破盾、打空、重锤命中、击杀、扔珍珠、开鞘翅、搭柱。
- `{habit}` 和 `{prediction}` 要等读人系统做出来才有。
