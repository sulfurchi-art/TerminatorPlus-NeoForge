# 4.14.0-BETA 换弹、边界与双配装内测

适配 Minecraft 1.21.1、Java 21、Superb Warfare 0.8.9.1-final-mc1.21.1；已在 NeoForge 21.1.249 验证原生兼容。TerminatorPlus 单独运行仍支持 21.1.1。

关服后备份旧 JAR，再替换 mods 内 TerminatorPlus，避免两版同时存在。卓越前线和原有依赖保持原安装。包内未捆绑第三方模组，本次没有操作正式服。

## 选择两套分级配装

```mcfunction
/bot preset use none
/bot settings defaultgear true
/bot settings gear warfare
/bot settings hardness 7
/bot create RifleBot
```

这些设置会保存，warfare 模式需准确版本卓越前线；自定义预设优先。切回原版用 `/bot settings gear vanilla`。等待生成后可用 `/bot inventory default warfare 7 RifleBot` 替换该机器人的装备，指令只改装备，AI 等级保持原值；末尾写 `all` 则更换所有机器人。装备及数量的 1–10 逐级表见 `SUPERB_WARFARE.md`。

原版 1 无附魔，此后逐级增加，10 为合法满附魔下界合金 OP 套，兼有剑斧、弓、重锤、鞘翅和有限图腾。卓越前线套使用原生枪、刀/合金剑、头盔/胸甲、弹药、医疗包与面包壳；保留通用图腾、鞘翅、烟花和珍珠。7+ 配 RPG；9+ 加 AWM、C4、TM-62。这个版本无注册腿/鞋，不混入原版护甲。原生枪不支持附魔，仅受支持装备逐级附魔。

8–10 会实际使用医疗包和食品。烟雾弹、手雷、装甲板、C4、TM-62 与引爆器目前只配给，自动使用待后续开发。新发枪是空膛，准备阶段请让机器人有时间依次完成真实换弹；没有直接填满弹匣。

## 本轮行为

- 换弹期间保留枪械，普通距离变化/主动拉近技能不抢手；切枪增加迟滞。无敌人时依次预装真实枪，包括 100 tick 的 RPG。
- 当前步枪已能射击时，不用珍珠或鞘翅直接冲到敌人身边。紧急撤离、脱困和抢位仍按原条件处理。
- 自主移动目标约束世界边界；坦克撤退有终点，并用原生刹车留惯性余量。低血坦克对原生零伤害近战不盲目撤退。
- 近处步兵可用原生机枪和驾驶碾压；爆炸安全距离按原生两倍半径评估，阻止朝近处障碍发射。车载射线排除同车乘员，随身枪仍检查同车友军。
- 7+ RPG 尝试真实掩体预装、侧后露头、发射后回缩；同队可以分诱饵/侧翼。长期换弹后搜索实际观察过的位置。

乘员指令沿用 `/bot vehicle crew <队长> nearest`、`board <机器人> <UUID> <座位>`、`go <驾驶员> <x> <y> <z>` 与 `leave`。`/bot vehicle status <机器人>` 和 `/bot info <机器人>` 增加装弹、瞄准、安全等待诊断。驾驶只使用原生输入。

## 建议复测

1. 5 级 AK-47+AA-12 的 5v5，两队 60 格：先按兵不动预装，再交战；检查所有人能开火、不会在双空枪间卡换弹，也不会立即冲成霰弹贴脸。
2. 150 格边界的 10 级 M1A2 双人对战，相距 70 格：观察主炮、低血撤退、停车和乘员存活；偶发不开炮时记录 `vehicle status`。
3. RPG 步兵对坦克：先装好弹，放真实可走掩体；观察侧翼开火和回缩。无遮蔽地形不保证能活着装弹。
4. 原版与卓越前线套分别检查 1、7、10 级装备、附魔、有限图腾及医疗包消耗。

## 结果和待修

真实卓越前线专项 **46/46 通过**；基础完整回归 **129 项通过、1 项失败，共 130 项**。基础失败：teamdive same side native takeoffs spread before a common smash with near member first。历史同向团队俯冲仍待单独修复。最低版本构建成功，JAR 完整性与主类逐字节检查通过；SHA256 和完整日志在包内。

单双乘员主炮对照在修改前也通过，尚未证实偶发不开炮就是车长遮挡。正式服三种对战仍需人工验收。开发期间补充的完整版报告新增直升机扫射/规避/乘员射界、载具回场、尾部登车等问题，留下一批；当前直升机只追加边界控制，不能视作这些问题已修好。

特殊制导/诱饵效果、复杂地形起降、投掷物/地雷自动操作、无人机和 10EX 仍未完成专门验收。没有百人 TPS 或异线程 AI 结论。范围和实现入口见 `SUPERB_WARFARE.md`、`AI_HARDNESS_PROGRESS.md` 与 `AGENTS.md`。
