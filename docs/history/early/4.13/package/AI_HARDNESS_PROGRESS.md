## 已实现机制

- [x] 1–10 难度档案，7 为旧战斗逻辑基线；低难度降低反应、攻击频率与技能覆盖。逐级数值可通过 SNBT 配置，不引入难度专属移动、血量或伤害乘数。
- [x] 每档默认装备，显式装备预设优先；8–9 默认带有限补给。10 保留旧自动回血，普通物资无限、装备不坏，图腾仍按原版消耗且可以死亡。图腾无限规则仍待设计决定。
- [x] 真实食物、恢复药水、金苹果和紫颂果的使用流程；主手动作互斥，过期举盾回调不会打断之后的进食。8–10 的实际盾牌使用达到原版 5 tick 后可格挡，普通机器人会主动预判来箭和近战动作；盾牌与图腾交换真实槽位，低血保留图腾，不抢占食物。
- [x] 8–10 剑斧走原版攻击，使用实际武器、攻击冷却与下落暴击；预设物品、模板武器在机器人之间独立，1–9 保留实际耐久损耗。
- [x] 重锤与鞘翅复用既有运动上限预判移动目标；功能场景验证可命中移动目标。
- [x] 低血撤离、安全位置采样、实际补给、临时掩体、紫颂果脱困和空中追踪补给；连续受击可触发珍珠、飞行或地面转移。

- [x] 8、9、10 分别生成并投掷 1、2、3 种原版力量、速度、跳跃提升药水；机器人自定义物理接入原版药水倍率。
- [x] 队伍共享集火、伤残队友支援和分散角度追击；10 级重锤队员先分散入场，再按各自预计接触时间安排俯冲，复用已有飞行和下落上限。

## 下一轮开发清单

1. **深化对手学习。** 在实际招式成功/失败记录之外，逐步识别可验证的走位、举盾、补给习惯，并据此调整进攻风格与假动作；目前学习仍是招式结果权重。
2. **扩展多步规划。** 当前已加入实际假动作、确认后推进的条件连招和失败/超时退出；继续完善更长的动作链、失败后的替代动作及对不同对手的计划选择。
3. **完善地形与防守。** 抢高地、对付枪械时贴掩体接近、以一打二的敌人排线，以及特殊模组投射物的防守适配。目前已有局部站位评分与普通高难自动盾牌防守，尚未覆盖上述完整地形策略。
4. **深化团队协作。** 恢复开发时先修复本次内测包的同向俯冲失步问题。已有实际跟随集火、护卫、三角色和伤员轮换；继续完善复杂地形下的护卫路线与治疗物品支援。已加入同向入场分散与按预计接触时间同步；继续验证更多人数、突变走位和复杂地形的成功率，不能把有限功能场景视为所有情况下都能同刻命中。
5. **加入游戏内团队指挥。** “跟我、集火、散开、撤、守这里”等指令与同队路由；接入时沿用实际服务端身份和权限，不依据离线名字授予管理权限。
6. **完善掩体退出与回收。** 明确破墙退出动作；将待回收掩体所有权保存到世界数据，实现重启后的回收。当前待回收队列只在本次服务器会话有效，无法识别所有绕开玩家事件的同状态方块替换。
7. **完善统计和台词触发。** 图腾消耗、击杀/死亡结算、完整对局统计和可验证的命中率；习惯预测与“读懂玩家”类台词须有实际观测支撑，当前不会填造未知槽位。
8. **补齐配置边界。** `playertarget` 目前只影响已有机器人；机器人实体及逐个临时覆盖不保存。`settings reload` 按设置、预设、台词逐文件重载，每个文件独立验证，但跨文件整体事务尚未实现。
9. **实战校准。** 相同装备下做相邻等级对战，再单独比较默认装备；统计移动靶重锤命中率、多队员俯冲实际同步率和安全恢复和珍珠截击成功率。现有功能场景不能证明每级胜率递增，也不能证明 10 已达到真人顶尖水平。
