# 4.10.0-BETA 人工内测包

适用 Minecraft 1.21.1 / NeoForge 21.1.1 及以上兼容版本 / Java 21。关闭服务端后，用本包 JAR 替换 `mods` 里的旧版 TerminatorPlus JAR，保留一份，再启动服务端。

## 当前验证结果

构建成功，JAR 元数据、资源和全部编译类一致性已核对。完整功能回归 **120 项通过、1 项失败，共 121 项**。

已知问题：10 级同队重锤机器人从同一侧起飞时，较近队员排在前面的路线仍偶发错过共同俯冲窗口；本次完整回归中实际砸击出手相差 **7 tick**。这一批的定向 10 项检查曾全部通过，但完整回归复现了失步，因此暂不标记为完整通过。停止后续开发，等待人工内测反馈。

## 快速开始

以下在有管理权限的玩家端执行。先给自己配好背包、护甲和副手，背包空出至少一格；预设会复制这套物品。

```mcfunction
/bot preset save playtest
/bot settings setgoal nearestenemy
/bot createpreset playtest TestBot 8 none
/bot info TestBot
```

生成需要等皮肤请求完成。生成后可切换个体难度：

```mcfunction
/bot settings hardness 9 TestBot
/bot settings hardness 10 TestBot
```

`/bot info` 可观察恢复/撤离状态、团队角色和已经建立的俯冲计划。7 级保留旧战斗基线，1–6 降低反应和技能覆盖；8–10 加入撤离补给与原版剑斧攻击。10 目前还有自动回血、无限普通物资和无耐久损耗，图腾仍会消耗。

## 团队内测

给预设加入重锤、鞘翅和烟花，重新保存后创建两名同队 10 级机器人；玩家留在敌方队伍或不入队。

```mcfunction
/team add bots
/bot createpreset playtest DiverA 10 bots
/bot createpreset playtest DiverB 10 bots
```

建议分别观察同侧与相对方向起飞、不同初始高度、移动目标、队友低血撤离和落点被临时方块挡住的情况。协同使用已有飞行、转向和下落上限；原版受击保护仍生效，两次同刻出手不代表一定产生两次伤害。

若想临时关闭团队战术，可用 `/bot settings ability teamwork false`；恢复用 `true`。这个开关会影响团队药水、护卫、分工和协同俯冲，不只影响已知失步问题。

## 反馈记录

遇到问题请记录：机器人难度、装备预设、团队人数、实际地形、触发前后的操作及 `/bot info` 状态。重锤相关问题最好附上录像，并区分没有起飞、没有下落、出手不同步或出手后未造成伤害。
