# 卓越前线（Superb Warfare）兼容调研笔记：10EX 难度

> 2026-10-04 调研，对象是服务器上安装的 `superbwarfare-0.8.9.1-final-mc1.21.1`。还没写任何代码，这里只是可行性结论和入口类，给以后实现的 AI 用。2026-10-05 补充了文末的"行为设计"和"数据参考"两节。

## 目标（用户的规划）

在 10 级之上加一个"末日级别"的 **10EX**：机器人会使用卓越前线的枪械、载具和各种道具。

## 结论：可行

**仓库：** [Mercurows/SuperbWarfare](https://github.com/Mercurows/SuperbWarfare)。
- 许可证 **LGPL-3.0**，允许别的模组调用它（本模组是 EPL-2.0，用软依赖的方式即可）。
- 用 **Kotlin** 编写，从 Java 调用没问题。
- 更新非常频繁，内部类随时可能变，所以要**锁定版本**。

**为什么可行：** 玩家的所有操作都是"客户端发消息、服务端执行"，而机器人本来就是服务端的玩家。在服务端用机器人的身份执行同样的逻辑，等于机器人在操作。

**入口：** 下面这些都在 `com.atsuishio.superbwarfare.network.message.send` 包里，是客户端发给服务端的消息。

| 消息 | 字段 | 用途 |
|---|---|---|
| `ShootMessage` | `spread`, `zoom`, `uuid`, `targetPos: Vector3f` | 开枪，**直接带了瞄准点** |
| `FireKeyMessage` | `type`, `power`, `zoom` | 开火键按下和松开（连发、蓄力） |
| `ReloadMessage` / `UnloadMessage` | | 换弹和退弹 |
| `ZoomMessage` / `SwitchScopeMessage` / `FireModeMessage` | | 开镜、切换瞄具、切换射击模式 |
| `VehicleMovementMessage` | `keys: Short`（按键位掩码） | **驾驶载具**：按"哪些键按下了"来驱动 |
| `VehicleFireMessage` / `SwitchVehicleWeaponMessage` / `ChangeVehicleSeatMessage` | | 载具开火、切换载具武器、换座位 |
| `DroneFireMessage` | | 无人机攻击 |
| `AdjustMortarAngleMessage` / `ArtilleryIndicatorFireMessage` | | 迫击炮和炮击 |
| `MeleeAttackMessage` / `LungeMineAttackMessage` / `ParachuteMessage` / `DoubleJumpMessage` | | 近战、刺雷、降落伞、二段跳 |
| `Radar*Message` | | 雷达 |

**两种接入方式：**
1. **伪造消息上下文（最快）：**
   - 自己实现一个 `IPayloadContext`，让 `player()` 返回机器人。
   - 构造上面的消息对象，直接调用它的 `handler(context)`。
   - 这样完全复用卓越前线自己的服务端逻辑，包括弹药、后坐力、散布、冷却、音效。
2. **调用底层函数（更稳）：**
   - 卓越前线**本来就支持生物用枪**：有 `data.mob_guns.MobGunData`，里面是射程、瞄准时间、半自动射击间隔、散布、是否开镜、备弹数，还有 `event.EntityUseGunEventHandler`。
   - 说明存在一条"以 `LivingEntity` 身份开枪"的服务端路径。找到这条路径直接调用，比伪造网络消息更不容易出问题。
   - 注意：它给生物加 AI 的逻辑只对 `Mob` 生效，机器人是玩家，不会自动获得这些 AI。

**可以订阅的事件（`api.event`）：**
- `ShootEvent.Pre/Post`、`ProjectileHitEvent`：知道"有人在对我开枪""我被打中了"，用来触发受压撤离和找掩体。
- `ReloadEvent`：抓对方换弹的窗口。
- `PreKillEvent`：击杀判定。

**载具（这个版本里的类名）：**
- 有 `PrismTank`（棱镜坦克）、`Annihilator`、`Kirov`（飞艇）、`Mortar`（迫击炮）、`Tow`、`SodayoPickUp`（皮卡，另有重机枪、火箭、TOW 改型）、`Truck`、`Speedboat`、`Drone`、`WheelChair` 等。
- 另外还有大量载具是数据驱动的（`data/vehicle`）。

## 建议的实现方式

**单独的兼容层：** 比如放在 `compat/superbwarfare` 包里。
- 只在检测到卓越前线时启用：`ModList.get().isLoaded("superbwarfare")`。
- 编译时只用 `compileOnly` 依赖，不打进 jar。

**锁定版本：** 只支持 0.8.9.1。
- 版本不匹配，或者调用抛异常，就关掉卓越前线相关的功能并打印日志，绝不能让服务器崩。

**自测：** 自测环境要装卓越前线和它的依赖（Kotlin for Forge、GeckoLib 等），只在装了的时候跑这部分场景。

**能力路线，从易到难：**
1. 拿枪、瞄准（`targetPos` 直接给）、开火、换弹、开镜、切换射击模式。按距离选武器：近距离用霰弹枪或冲锋枪，中距离用步枪，远距离用狙击枪，打载具或人群用火箭筒。
2. 投掷物：手雷、C4、阔剑地雷（布在自己周围）、烟雾弹（当掩护）。
3. 固定火力：迫击炮、TOW、皮卡重机枪（只开火不开车）。
4. 无人机：起飞、侦察、自杀式攻击。
5. 驾驶地面载具：需要配合路径规划，理解载具的运动。
6. 驾驶飞行器：最难。

**反制意识：**
- 用 `ShootEvent` 和 `ProjectileHitEvent` 感知枪线，找掩体、绕侧翼。
- 对方坐进载具时，切换到火箭筒或 C4。

**需要注意：**
- 大量子弹和爆炸会影响服务器性能。
- 爆炸会破坏地形（看卓越前线的配置）。
- 机器人队友之间的友伤要处理。

**第一步原型：** 让一个机器人拿一把枪，对着靶子打一梭子再换弹。跑通了，再往下做投掷物和载具。

## 乘员组与战术小队（用户规划）

**多人共同操作一台多座载具：**
- 卓越前线的载具本来就分座位，每个座位有各自的武器：换座位用 `ChangeVehicleSeatMessage`，切换武器用 `SwitchVehicleWeaponMessage`，驾驶员用 `VehicleMovementMessage` 开车。
- 乘员组的分工：
  - **驾驶员：** 规划路线，把车停在炮手有射界的位置，打不过就倒车脱离。
  - **炮手：** 各自瞄准、开火。
  - **车长：** 发现目标、分配目标，有雷达时用雷达。
- 载具快爆炸时全员弃车，下车后变回步兵小队继续打。
- 座位数量和每个座位的武器，从载具数据（`data/vehicle`）里读。

**步兵战术小队：**
- **兵种：** 突击、狙击、机枪（压制）、反坦克（火箭筒）、工兵（C4、地雷）、无人机操作员。
- **战术动作：**
  - 交替掩护前进：一组前进，另一组掩护。
  - 机枪压制正面，突击组从侧翼包抄。
  - 敌方上了载具，反坦克兵就上。
- **指挥：** 由队长机器人下令。也可以让真人玩家当队长，机器人听他指挥，接上台词库里的"对队友"指令和队友行为。
- **前提：** 复用难度系统里的团队重构（共享黑板、分工、包抄槽位）。
- **台词：** 加一套军事风格的喊话，比如"接敌！""换弹，掩护我！""RPG 准备！""车要炸了，下车！"。

## 放在主体 mod 里（用户决定，2026-10-04）

> 卓越前线兼容不拆成附属 mod，直接放在主体 mod 里，作为可选的附加功能。理由是：这一块目前没人做过，先做着玩。

**没装卓越前线时，主体必须照常运行。** 做法：
- **依赖声明：** 在 `neoforge.mods.toml` 里把卓越前线声明成可选依赖（`type="optional"`），版本范围锁定在 0.8.9.1。装了卓越前线时，它会先于本模组加载。
- **编译方式：** 只用 `compileOnly`，卓越前线的代码不打进 jar。jar 可以从本地拿，也可以从 Modrinth 的 Maven 仓库拿。
- **代码隔离：**
  - 所有引用卓越前线类的代码都只放在 `compat/superbwarfare` 包里。
  - 主体代码只通过一个自己定义的接口（比如 `WarfareSupport`）调用这部分功能，这个接口默认是什么都不做的空实现。
  - 只有检测到 `ModList.get().isLoaded("superbwarfare")` 时，才加载真正的实现。
  - 否则没装卓越前线时一碰到这些类，就会抛 `NoClassDefFoundError`。
- **出错不崩服：** 版本不匹配或者调用出错时，自动关掉这部分功能并打印日志，不能让服务器崩。
- **10EX 档：** 只有装了卓越前线才出现。没装时最高就是 10 级。

## 行为设计：人机在卓越前线里该怎么打（2026-10-05）

> Claude 提出，用户看过并同意。细化了上面的"能力路线"和"乘员组与战术小队"。文中数字都来自 0.8.9.1 的数据文件，完整表格见文末"数据参考"。

### 总原则

- **强在懂规则，不在枪法数值。** 卓越前线的克制关系（什么武器打什么目标、什么时候露头、什么时候压上）都写在它自己的数据文件里。人机运行时直接读这些数据来做判断，不要把数值抄进代码。
- **不改卓越前线的数值，也不作弊。** 难度只来自决策和操作精度（反应、瞄准误差、压枪），和难度系统的思路一致。
- **用枪时的瞄准误差要比用剑大。** 枪比剑致命得多：AWM 一枪 36，爆头 ×3 就是 108。同一级的人机如果拿枪和拿剑一样准，5 级拿 AWM 就成了外挂。
- **枪械操作按 1～10 级正常分档。** 用预设给任何等级的人机发枪都能用，水平和等级相符。10EX 的区别不是"枪法更准"，而是会打现代战争：载具、乘员组、无人机、炮兵、反装甲、兵种分工一起上。

### 一、单兵用枪

**按距离和目标选武器，而不是手里拿什么就用什么：**
- 8 格内：霰弹枪或冲锋枪。M870、AA-12 一发打出 12 颗弹丸，MP5 每分钟 900 发。
- 中距离：突击步枪。只在近处全自动，稍远打 3～5 发短点射。
- 远距离：射手步枪开镜单发，再远用栓动狙。
- 坦克和步兵战车用火箭筒、标枪、C4；直升机用 IGLA。
- 武器分类可以用卓越前线的物品标签：`smg`、`rifle`、`shotgun`、`sniper_rifle`、`machine_gun`、`launcher`、`gun`。标签不全，比如 RPK 和 M60 只在 `gun` 里，需要按射速、弹匣这些数据补充判断。

**瞄准：**
- **能打头就打头。** 爆头倍率（字段 `Headshot`）：步枪 ×2，SVD 和 MK-14 ×2.5，栓动狙 ×3。
- **按弹速算提前量。** 字段 `Velocity` 的单位推测是格/tick：M79 是 3.75，也就是每秒 75 格，和真实 M79 的 76 m/s 吻合。
  - 步枪是 36～47，中近距离几乎不用提前。
  - RPG 只有 4，还有重力 0.03；M79 走抛物线。用这两样打移动目标必须算提前量和下坠，低难度基本打不中跑动的人。
- **压枪。** 全自动会往上飘（`RecoilX`、`RecoilY`）。低难度扫几发就飘了，高难度打点射。
- **看护甲。** `BypassesArmor` 是无视护甲的比例：AK 0.2，AWM 0.8，NTW-20 是 1。对面穿满附魔下界合金时，高难度会换狙击枪或炸药，不拿 AK 硬磨。

**换弹（最能拉开水平差距的地方）：**
- 换弹时间很长（`NormalReloadTime` 是没打空、`EmptyReloadTime` 是打空，单位 tick）：AK 是 52 / 65，M60 是 114 / 133。
- 高难度：子弹快打空时躲到掩体后换；近距离打空了直接切手枪，不在对面眼前换弹。
- 抓对面换弹：
  - 数对面打了几发（`Magazine`）：AK 30 发，M870 8 发，AWM 5 发，SVD 10 发。
  - 对面一换弹就压上去。用卓越前线的 `ReloadEvent` 判断谁在换弹。
- 低难度：打空才换，站在原地换。

**走位、听觉和道具：**
- 露头、开几枪、缩回去，不站在空地上对射。狙击手开完枪就换位置。
- **听枪声。** 每把枪有 `SoundRadius`：格洛克 8、AK 14、AWM 18、NTW-20 22。单位待确认，按玩家实际能听到的范围来换算。人机听到枪声后，接 8～9 级已有的听觉和"最后已知位置"搜索，不开透视。
- **烟雾、手雷和地雷：**
  - 过空地前扔 M-18 烟雾弹。
  - 对面缩在掩体后面不出来，就扔手雷（M67、RGO）把人逼出来。
  - 守点时在路口布阔剑地雷。
- **被压制时**（子弹从身边飞过，可以用 `ShootEvent`、`ProjectileHitEvent` 判断）：低难度会慌，要么乱跑，要么一直缩着；高难度先找掩体再还手。

### 二、对付载具

载具数据里的 `DamageModifiers` 是一串按顺序生效的规则：
- `All - 20`：所有伤害先减 20。`All * 0.2`：再乘 0.2。
- `#...` 按伤害类型标签、`@...` 按造成伤害的实体，单独改倍率。
- `$...` 是表达式。

人机用这串规则估算"这把武器打这台车有没有用"。优先找卓越前线自己计算这串规则的代码来调用，不要自己重写解析。

- **主战坦克对子弹免疫。** M1A2、T-90A、ZTZ-99A、YX-100 和 PLZ-05 自行火炮的 `#superbwarfare:projectile` 都是 0。人机看到这些车，第一反应应该是喊"坦克！"、散开、让反坦克兵上，不开枪浪费子弹。拿步枪打坦克是低难度才会犯的错。
- **M1A2 最怕 C4 和反坦克雷。** C4 ×6，TM-62 反坦克雷 ×2.5，火箭弹只有 ×1.1。所以工兵的正确打法是绕到死角贴 C4，或者在它必经的路上埋雷。
- **角度和部件。** M1A2 的伤害规则里有一项按来袭角度计算（`$entity.getSourceAngle(source, 0.3) * damage`）。它还有部件血量 `PartHealth`：炮塔 100，左右履带各 100，主副发动机各 150。高难度会绕到侧后方打，并且挑部件打。部件打坏后的具体效果还没查。
- **标枪。**
  - 锁定要 20 tick（`SeekTime`），目标要在 10° 以内（`SeekAngle`）、256 格以内（`SeekRange`）。
  - 有直射和攻顶两种模式（`Dir`、`Top`）。
  - 坦克有诱饵（`HasDecoy`）。如果诱饵有冷却，高难度先锁一次把诱饵骗出来，等失效再打第二发。
- **直升机。** 子弹对 AH-6 只有 ×0.16，对 Mi-28 只有 ×0.03；火箭弹对 AH-6 却是 ×3。所以打直升机用 RPG 或 IGLA，不用步枪。

### 三、开载具和乘员组

座位表在载具数据的 `Seats` 里，包括每个座位的 `Weapons`、能不能用手（`BanHand`）和视角范围。人机按座位分工。按卓越前线的惯例，0 号位是驾驶员，这一点待实测确认。

| 载具 | 座位 |
|---|---|
| M1A2 | 0 号位：主炮和同轴机枪。1 号位：车长遥控机枪。2 号位：站在炮塔上，能用自己的枪。3、4 号位：挂在车尾，不能用手 |
| YX-100 | 0 号位：主炮和机枪。1 号位：副炮。2 号位：蜂群无人机。3、4 号位：挂在车尾 |
| BMP-2 | 0 号位：机炮、机枪和导弹。1～6 号位：每个座位一挺射击孔机枪（MG1～MG6），正好载一个步兵班 |
| AH-6 | 0 号位：驾驶员，管机炮和火箭。1～3 号位：没有武器也没禁手，能用自己的枪，两侧长椅相当于门炮手 |
| Mi-28 | 0 号位：驾驶员，管火箭和两种导弹。1 号位：炮手，管机炮和导弹 |
| AC-130H | 0 号位：驾驶员，只负责飞。1～3 号位：M61、博福斯、M102 三门炮，各一个炮手。4、5 号位：乘客 |

**各个位置的打法：**
- **驾驶员：**
  - 不冲进对面火箭筒的射程。
  - 停下来开炮，不边开边打。
  - 车受重伤先倒车脱离。
  - 被锁定就放诱饵。
- **炮手：** 先打扛火箭筒和标枪的人，他们对坦克威胁最大，然后才打载具。零散步兵用机枪处理，不浪费主炮。
- **步兵战车：** 在交战距离外放下步兵，用机炮掩护，步兵往前推。
- **车快炸了：** 全员下车，变回步兵继续打。有维修工具的人躲到掩体后面修车。
- **直升机：** 打一轮就拉开，不悬停在空中当靶子。被防空导弹锁定就放诱饵、贴地飞。
- **AC-130H：** 驾驶员绕着目标转圈，三个炮手各自开火。这是最典型的多人合力载具。

### 四、小队

**五人一组：**
- 队长：突击步枪。
- 机枪手：M60 或 RPK，负责压制。
- 射手：SVD 或 MK-14。
- 反坦克兵：RPG 或标枪。
- 工兵兼医疗兵：带 C4、阔剑、医疗包和维修工具。

**打法：**
- 机枪手压住正面，突击手和射手绕侧翼。
- 前进时一半人移动，另一半人架枪掩护。
- 有队友倒下时，旁边架枪的人立刻打掉那个露头的敌人。
- 打不过就整队撤退，不一个一个上去送。
- **喊话：** 接台词库，比如"接敌！""换弹，掩护我！""RPG！""坦克，找掩体！"。喊话同时也是给玩家的信息：听到就知道对面要干什么，这算公平的压力。
- **真人当队长：** 人机听真人指挥，比如跟我、集火、散开、撤。这和 4.10 进度清单里的"游戏内团队指挥"是同一件事。
- 10 级现有的诱饵、侧翼、弓手分工，可以直接映射到这几个兵种上。

### 五、按等级分

| 等级 | 表现 |
|---|---|
| 1～3 | 不开镜扫射，瞄身体而且误差大；打空了站在原地换弹；不扔雷，不上车 |
| 4～6 | 中远距离开镜点射；躲到掩体后换弹；会扔手雷，会按距离换枪；能操作固定火力，比如迫击炮、陶式导弹、皮卡重机枪 |
| 7～9 | 瞄头，算提前量，抓对面换弹；会用烟雾、阔剑和 C4；会开地面载具，两三人组成乘员组 |
| 10 | 包含以上全部，加上原有的信息优势。备弹无限，但弹匣照样要换，保留换弹的空窗给玩家反制。载具能源无限，但血量是真的 |
| 10EX | 末日级：步兵小队、载具、无人机（侦察、自爆、蜂群）、迫击炮和炮兵、防空全部一起上。多个小队互相配合，由一个指挥官人机分配任务 |

### 底线

1. **1～9 级不透视、不自瞄。** 只能看到视线里的人，听到枪声才知道你在哪。人机也不能在 0.05 秒内转身 180° 爆头。
2. **几百人混战要限制同时开火的人数。** M134 一把枪每秒就打 20 发，大量子弹实体会拖慢服务器。

### 优先级

先做"按距离和目标用枪"和"对付载具的判断"。这两块收益最大、风险最小，都属于上面能力路线的第 1 步，因为火箭筒和标枪在卓越前线里也算枪。开载具和乘员组放到后面。

## 数据参考（0.8.9.1）

**数据在哪：** 都在卓越前线 jar 的 `data/` 下，能被数据包覆盖。所以运行时要读卓越前线已经加载好的数据，不要直接读 jar 里的文件，也不要把数值抄进代码。
- `data/superbwarfare/sbw/guns/<id>.json`：枪械数值。
- `data/superbwarfare/sbw/vehicles/<id>.json`：载具的血量、座位、武器、伤害规则、部件血量和诱饵。
- `data/superbwarfare/sbw/mob_guns/`：生物用枪。目前只有骷髅拿 M79。
- `data/superbwarfare/sbw/drone_attachments/`：无人机挂载。
- `data/superbwarfare/tags/item/`：武器分类。
- `data/superbwarfare/tags/entity_type/`：`at_rocket`、`aa_missile`、`aerial_bomb`、`mine`、`decoy`、`can_repair` 等。
- 中文名在 `assets/superbwarfare/lang/zh_cn.json`。
