# 4.17.0-BETA 载具寻路与协同内测

Minecraft 1.21.1；TerminatorPlus 独立运行最低 NeoForge 21.1.1。卓越前线精确适配 Superb Warfare 0.8.9.1-final-mc1.21.1，需 NeoForge >=21.1.203 和其原生依赖。

关服后备份旧 JAR，将 mods 中的 TerminatorPlus 替换为包内 `TerminatorPlus-NeoForge-1.21.1-4.17.0-BETA.jar`，避免两个版本并存。卓越前线及其依赖沿用现有安装，本包不捆绑第三方模组。

本轮优化坦克等地面车绕墙、车宽/地面支撑、水沟避让、堵塞安全倒车；友军车距与迎面右侧错车；8–10 级 teamwork 正面/侧翼分工、有效射程站位、受击换弹寻掩体。直升机优化航路体积检查、提前爬升/减速避障、多机分路和预判悬停/升高分离。炮弹安全检查包含友军车体。所有驾驶依然通过原生键盘/鼠标输入，不额外修改载具机动力。

沿用原有 crew/board/go/leave 命令。先把机器人加入相同的原版 scoreboard team，启用 vehicles、vehicleweapons、helicopters、teamwork；协同进攻来自机器人已经发现的相同敌人。显式 go 路点优先，安全避让仍生效。info 的 vehiclePilot 与 nav 可用于观察状态。

建议人工内测：长墙与窄门、坑洞/水沟、迎面同队两车、友军突然变道、原生敌坦克对抗、换弹受击后的退避、双机进场与山坡/高墙避障。检查是否出现长时间 ROUTE_PLANNING/OBSTRUCTED，记录机器人等级、team、载具型号、坐标与 info 状态。

固定翼自动驾驶未实现。复杂坡道、洞穴、巨大迷宫、实际多人空战与百人 TPS 未验证；保守外接体积可能拒绝斜向窄路。异线程性能实验仍暂停。本轮没有部署/重启正式服。

最终原生专项 **80/80 通过**，包括新增七项；基础回归 **127/130 通过**，失败为边界步兵撤离回血及同向团队俯冲两种顺序。最低版本构建成功，全部 174 个编译类已核对。基础失败尚未修复，详细测试与构建结果见 `validation-4.17.0.txt` 和 `docs/validation-4.17.md`；完整原始日志随包保存，开发期间的失败尝试另放 `process/`。旧 4.16 JAR/ZIP 保留。
