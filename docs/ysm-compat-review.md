# YSM 联动审查与后续范围

2026-10-05。资料来自本轮附件 `ysm-compat-notes.md` 与更新后的 `playtest-report-4.13.md`；其正式服实验为外部报告，本工作区未重复客户端实验。4.15 内测包尚未实现 `/bot ysm` 或 YSM 预设字段。

## 与当前代码的差异

| 需求 | 当前状态与必要改动 |
|---|---|
| 指定模型与贴图 | 当前没有 YSM 桥接。按已安装模组和服务端命令树检测，以服务器指令调用公开 `ysm model set`；避免编译依赖、混淆内部类或反射。 |
| 只让使用 YSM 的机器人进入玩家列表 | `Bot.createBot` 只在生成时读取全局 addplayerlist，`inPlayerList` 为私有状态。需要每个机器人的加入/退出入口，不能通过全局开关临时切换。 |
| UUID 精确定位 | 当前只将机器人加到 PlayerList.players，不能假定所有原版按 UUID 查询入口都能找到它。实现时需要核对原版玩家索引与 YSM 目标解析，验证重名机器人不会串模型。 |
| 保留模型、隐藏 Tab | 当前 render 根据 inPlayerList 发初始化包。需要让创建、后加入客户端和重连统一处理 listed 状态；UPDATE_LISTED=false 后模型是否仍显示必须客户端实测。 |
| 装备预设 | 当前 Profile 支持难度、队伍、人设、皮肤和能力，没有模型/贴图字段。需扩展校验、文本持久化及异步生成的配置快照。 |
| 生成后设置模型 | 当前加入世界后立即 manager.add；需要主线程延迟任务，并检查实体仍存活、维度及请求是否已被替换，避免 reset 后过期任务恢复幽灵玩家。 |
| 死亡和移除 | Bot.removeBot 已按 inPlayerList 从 players 清除并移除客户端档案，PlayerListMixin 禁止机器人写 playerdata。新增索引和模型状态也必须在相同生命周期清理。 |
| 后进服/重连 | 当前登录逻辑补发机器人档案，不会执行 YSM 模型重同步。先验证 YSM 的原生同步是否足够；需要时再按已有模型记录重发，不能对普通机器人全局启用。 |
| 中文 ID 与错误 | 使用直接 Java 字符串派发，按 Brigadier 字符串规则转义 model/texture，禁止把参数当完整指令拼接。未知模型、模组缺失和命令失败应报告结果且不破坏普通 AI。 |

## 实现与验收顺序

先做软依赖检测和公开命令桥接，再做单机器人玩家列表生命周期、模型命令及预设保存。无 YSM 环境必须保持可独立启动。模拟命令可以验证路由、参数转义和生命周期，但不能证明客户端显示模型。

真实 YSM 2.6.5 客户端需要验收：当前在线玩家看到模型、后进服/重连、隐藏 Tab 后同步、重名隔离、中文自定义模型、死亡/reset 后无残留。未安装该 JAR、未执行这些测试前，不标记为已验证。

进入玩家列表会影响 @a/@p、在线人数及睡觉人数统计；仅适用于配置 YSM 的机器人，并在玩家用法中说明。只隐藏 Tab 不会取消这些服务端影响。

最新实测报告另列低级乘员、有限补给命令和观战台词；4.15 尚未实现这些项目。两套分级默认装备已在 4.14 完成。报告中的运维命令和第三方转述不自动执行，也不作为修改正式服的授权。
